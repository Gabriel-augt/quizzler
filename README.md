## Português

Um projeto de **Quiz com 30 questões dinâmicas**, onde **apenas 10 questões são exibidas por rodada**, cada uma com 4 alternativas. A cada atualização da página, novas perguntas e alternativas são selecionadas aleatoriamente, proporcionando sempre uma experiência diferente.

### 💡 O projeto foi desenvolvido para praticar:

- Dinamicidade e aleatoriedade no front-end.
- Internacionalização (i18n) para múltiplos idiomas.
- Componentização com Vue 3 (Composition API).
- Estilização responsiva e moderna com Tailwind CSS.

### ⚙️ Funcionalidades

🎲 Exibe 10 perguntas aleatórias de um banco com 30 perguntas totais.

🔄 A cada recarregamendo da página, um novo conjunto de perguntas é sorteado, assim como a ordem das alternativas.

🌐 Suporte multilíngue (ex: pt-BR, en-US) via Vue I18n.

📱 Layout responsivo e agradável com Tailwind CSS.

### 💻 Tecnologias utilizadas

* Vue.js 3 (Composition API) com I18n para suporte multilíngue.

* Tailwind CSS para estilização.

## English

A **Quiz project with 30 dynamic questions**, where **only 10 are displayed per round**, each with 4 alternatives. On every page reload, new questions and shuffled alternatives are selected randomly, always providing a fresh experience.

## 💡 The project is designed for practice:

- Dynamicity and randomness on the front-end.
- Internationalization (i18n) for multiple languages.
- Componentization with Vue 3 (Composition API).
- Responsive and modern styling with Tailwind CSS.

## ⚙️ Features

🎲 Displays 10 random questions from a bank of 30 total questions.

🔄 Each time the page is reloaded, a new set of questions is drawn, as is the order of the alternatives.

🌐 Multilingual support (e.g. en-BR, en-US) via Vue I18n.

📱 Responsive and pleasant layout with Tailwind CSS.


### 💻 Technologies used
* Vue.js 3 (Composition API) with I18n for multilingual support.

* Tailwind CSS for styling.

## Español

### 💡 El proyecto fue desarrollado para practicar:

- Dinamismo y aleatoriedad en el front-end.
- Internacionalización (i18n) para múltiples idiomas.
- Componentisación con Vue 3 (API de composición).
- Estilización responsiva y moderna con Tailwind CSS.

### ⚙️ Funcionalidades

🎲 Muestra 10 preguntas aleatorias de un banco de 30 preguntas en total.

🔄 Con cada recarga de la página, se dibuja un nuevo conjunto de preguntas, así como el orden de las alternativas.

🌐 Soporte multilingüe (por ejemplo, en-BR, en-US) a través de Vue I18n.

📱 Diseño responsivo y agradable con CSS de Tailwind.

### 💻 Tecnologías utilizadas

* Vue.js 3 (API de composición) con I18n para soporte multilingüe.

* Tailwind CSS para estilización.
